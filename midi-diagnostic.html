Donner DDP-100 MIDI Diagnostic

This page tests what MIDI the piano actually sends and whether Local Control can be turned off. Do not assume CC 122 works until the experiment says so.

Serve from localhost, not as a file. In this folder run python3 -m http.server 8000, then open http://localhost:8000/midi-diagnostic.html. Use Chrome or Edge. Web MIDI will not work from a file:// URL.

Local Control Test

Follow these steps in order. The piano may ignore Local Control. Speaker behavior plus the logs are the evidence.

  1. Connect the DDP-100 as both MIDI input and MIDI output.
  2. Press Play Middle C and verify the piano speakers play Middle C.
  3. Press Local Control OFF.
  4. Physically press piano keys.
  5. Check whether MIDI Note On/Off still appear in MIDI IN, but the piano speakers stay silent.
  6. Press Play Middle C again and check whether the browser can still make the piano speakers play.
If E and F both work: MIDI IN still shows physical keys, those keys stay silent, and Play Middle C still sounds. Browser-controlled note filtering is possible.

2. MIDI output tests

These send standard MIDI. They are disabled until an output device is selected. No SysEx is sent.

3. Play a piece through the piano

This walks the selected piece in time and sends its notes to the DDP-100, the same way Play Middle C does. Tempo and durations come from the piece JSON. Connect MIDI output first.

4. Filter Mode (optional)

When enabled, physical keys are received but not blindly echoed. Only the allowed note is sent back. Sustain (CC 64) is still forwarded. Other notes stay silent if Local Control is actually off.
